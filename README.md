# TextRestore — 隐蔽字符还原工具

ChatGPT / Claude Code / Gemini 等模型有时会在输出中偷偷插入或替换一些**肉眼几乎无法分辨的字符**（全角字符、零宽字符、花体字母、西里尔相似字母等），用来识别中文用户。本工具把这类"隐蔽字符"自动还原为对应的普通英文字符。

## 功能特性

- 简洁图形界面（tkinter，仅标准库）
- 输入即自动转换，上输入 / 下输出双文本框
- **diff 高亮**：输入框中被替换的字符飘红，输出框中还原后的字符飘绿，一眼看出模型替换了哪些位置
- **选中联动（IDE diff 效果）**：鼠标框选任一边的内容，另一边的对应区域同步浅蓝高亮；选中背景为自定义浅蓝色（非系统默认蓝），深浅主题一致
- **滚动同步**：输入/输出框滚动位置保持一致（滚轮、滚动条、键盘翻页、拖拽选中的自动滚动均可）
- **自适应布局**：窗口缩放时两个文本框等高均匀分配空间，按钮始终可见
- **深色主题**：一键切换
- **中/英双语 UI**：设置-还原选项底部可切换「中文 / English」，默认按系统语言自动选择；所有界面文本（含设置页、状态栏）即时切换并持久化
- **新图标**：靛蓝→紫渐变圆角方块 + 红绿分色字母 A（左红=被替换、右绿=已还原），寓意隐蔽字符还原
- **设置面板**：还原选项收纳在"设置"窗口中，主界面更简洁；状态信息独占一行
- **iOS 风格开关**：主界面"包含前缀/包含后缀"与设置页的全部还原选项均改为苹果 UI 样式的滑动开关（绿色开启 / 灰色关闭 + 动画过渡 + 超采样抗锯齿平滑圆角），一眼看清状态
- **前后缀**：设置中可配置多行前缀/后缀（如用 markdown 代码块包裹输出），主界面勾选"包含前缀/包含后缀"即可附加到输出结果
- **全设置持久化**：主题、还原选项、前后缀、字体颜色全部保存到 `%APPDATA%\TextRestore\config.json`，重启自动恢复
- **字体与颜色自定义**：设置-外观页可为输入框/输出框**分别**设置字体、字号、替换字符（diff 标记）的前景色/背景色、高亮（选中/联动）的前景色/背景色；颜色可随时"恢复默认（跟随主题）"
- 11 类还原，均在设置中独立开关：
  1. 全角转半角：`ＡＢＣ１２３` → `ABC123`
  2. 中文标点转英文：`，。？！《》“”` → `,.?!<>""`
  3. 花体/数学字体：`𝐀𝐁𝐂𝟏𝟐𝟑` → `ABC123`
  4. 上下标：`x²y₃` → `x2y3`
  5. 相似字母（西里尔/希腊/小型大写）：`СА ᴀᴋ` → `CA AK`
  6. 删除不可见字符：零宽空格/连接符/BOM/双向控制符等
  7. 特殊空格归一：不间断空格/窄空格 → 普通空格
  8. **日期时间格式**：`2024年1月5日下午3点` → `2024-01-05 15:00`（含 `下午/上午/晚上` 等标记与中文数字 `二零二四年一月五日`）
  9. **AI 提示词标记**：`<\|im_start\|>`、`[INST]`、`<\|system\|>` 等残留 token → 删除
  10. **移除 AI 署名注释**（默认关闭）：匹配 "Generated by AI" 等签名的注释行 → 删除
- 自动删除输入末尾多余的换行符（可在选项中关闭），并在输入框中标注
- 一键复制结果，状态栏统计各类还原数量

## 使用

### 运行源码

```bash
python text_restore.py
```

### 使用发布版

从 [Releases](../../releases) 下载 `TextRestore.exe`（Windows 单文件，无需安装 Python，双击即用，无控制台窗口）。

## 从源码打包

```bash
pip install pyinstaller pillow
python build_icon.py    # 生成 icon.ico
pyinstaller --noconfirm --clean --onefile --windowed --name TextRestore --icon icon.ico text_restore.py
```

产物位于 `dist/TextRestore.exe`。
